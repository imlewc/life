# Life Window Atlas

一个围绕“人生关键时间窗口”概念制作的静态可视化网页。

页面将低龄关键期与成年阶段放进同一套时间轴逻辑里，通过年龄滑块、阶段提示、状态摘要和窗口卡片，展示不同人生议题在不同年龄段的开启、收紧与关闭节奏。

## 预览

这个项目不需要构建，直接打开 `index.html` 就可以查看。

如果你想用本地服务预览：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

## 功能

- 年龄滑块联动，支持 `0-80` 岁视角切换
- 快捷年龄按钮，快速跳转关键阶段
- 窗口状态实时计算：`待开启`、`黄金期`、`补救期`、`已关闭`
- 焦点窗口区域，展示当前最值得关注的卡片与时间轴
- 汇总卡片，统计当前年龄下的窗口分布
- 同时覆盖低龄生物/心理关键期与成年社会竞争窗口
- 支持从 `data.json` 读取数据；直接双击打开时会自动回退到页面内置数据

## 文件结构

```text
.
├── README.md
├── data.json
├── index.html
└── init.md
```

- `index.html`: 主页面，包含样式、交互逻辑和兜底数据
- `data.json`: 主数据源，定义窗口条目
- `init.md`: 最初的需求草稿与设计说明

## 数据格式

`data.json` 中每条数据采用统一结构：

```json
{
  "id": 101,
  "cat": "感知",
  "title": "视听觉布线",
  "range": [0, 3],
  "lock": 6,
  "penalty": "98%",
  "cost": "Extreme",
  "desc": "视觉与听觉皮层的关键发育期。"
}
```

字段说明：

- `id`: 唯一标识
- `cat`: 类别
- `title`: 窗口名称
- `range`: 最佳执行期
- `lock`: 强制力锁死点
- `penalty`: 错过后的损失强度
- `cost`: 补偿成本等级
- `desc`: 简短描述

## 当前内容范围

当前版本已覆盖：

- 低龄关键期：感知、动作、感统、第二语言、数感、安全感、情绪调节、自我意识、身高干预
- 成年窗口：学历、专业训练、创业、迁移、深睡恢复、财务复利、生育、认知重塑、老人照护等

## 后续可扩展方向

- 增加窗口筛选：按类别、成本、年龄段过滤
- 增加详情弹窗：展示更长解释、案例和建议
- 接入后端或 CMS：让窗口内容可在线维护
- 增加分享图和封面图，方便在 GitHub 或社交平台展示
- 拆成 Vue / React 项目，便于组件化维护

## 说明

这个项目目前是一个单页静态 Demo，重点在于视觉呈现和时间窗口逻辑表达，不包含医学、教育或心理学上的严格诊断结论。更适合用作概念演示、内容产品原型或交互提案基础。
