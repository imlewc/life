# Life Window Atlas

一个把“人生关键时间窗口”做成全年龄时间轴的静态网页 Demo。

[在线预览](https://imlewc.github.io/life/) | [数据文件](./data.json)

## 项目简介

这个页面把低龄关键期和成年阶段放进同一套可视化系统里，用年龄滑块去观察不同窗口在不同年龄下的状态变化：

- `待开启`
- `黄金期`
- `补救期`
- `已关闭`

页面更偏内容产品原型，而不是传统后台或工具站。重点在于把抽象的“时间窗口”概念做成直观、可浏览、可讲故事的单页体验。

## 主要内容

当前版本已覆盖：

- 低龄关键期：视听觉布线、精细动作、感统协调、第二语言母语化、数感建立、绝对音感、安全感、情绪调节、自我意识、身高干预
- 成年窗口：学历跃迁、专业训练、创业试错、财务复利、深睡恢复、迁移、生育、认知重塑、老人照护等

## 功能

- 年龄滑块联动，支持 `0-80` 岁视角切换
- 快捷年龄按钮，快速跳到关键阶段
- 状态摘要区，统计当前年龄下的窗口分布
- 焦点窗口区，自动展示更值得关注的条目
- 卡片自动排序，同步反映年龄变化
- 支持从 `data.json` 读取数据；直接打开 HTML 时会回退到页面内置数据

## 数据格式

`data.json` 中每条记录采用统一结构：

```json
{
  "id": 101,
  "cat": "感知",
  "title": "视听觉布线",
  "range": [0, 3],
  "lock": 6,
  "penalty": "98%",
  "cost": "Extreme",
  "desc": "视觉与听觉皮层的关键发育期。"
}
```

字段说明：

- `id`: 唯一标识
- `cat`: 分类
- `title`: 窗口名称
- `range`: 最佳执行期
- `lock`: 锁定年龄
- `penalty`: 错过后的损失强度
- `cost`: 补偿成本等级
- `desc`: 描述文本
